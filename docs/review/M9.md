# M9 — 아이콘 자리 · 정보 다이어트 · 클리어 보상 · 관측 추천 · 대안 루트 · Cloudflare Pages

커밋: `M9a: 데이터·core`, `M9b: UI`, `M9c: 배포·문서`

## 무엇을 했나

M8 루트 화면은 텍스트만으로 기프트·팩을 식별했고, 인게임에서 이미 보이는 정보(조합법·범용 드랍 위치·별빛 수치)를 반복했으며, 시간표 블록 안 글자가 잘렸습니다. 이번에는 (1) 기프트 아이콘·팩 이미지 **플레이스홀더**를 UI 전체에 두고 조건 판정을 아이콘 테두리 색으로 옮겼고, (2) 조합·범용·별빛·관측 옵션·범례 5개를 제거했으며, (3) 블록이 내용에 맞춰 자라고 호버한 층이 넓어지게 했습니다. 데이터 쪽에서는 사용자가 지목한 「획득 위치 없는 기프트」를 조사해 **EXTREME 팩 클리어 보상 10종**과 **히든 전투 보상 4종**을 파생했고, 관측 데이터 파일에서 **관측 가능 기프트 목록(312종)**과 비용표를 읽어 `verified: true`로 올렸습니다. 플래너는 관측 개수를 묻는 대신 지정 → 구제 → 유연성 순으로 관측을 추천하고, 팩 충돌이 남으면 기프트를 하나씩 뺀 **대안 루트**를 만듭니다. 배포는 Cloudflare Pages(Git 연동)로 바꾸고 GitHub Pages는 수동 예비로 남겼습니다.

## 결정과 규칙

- **관측 적격은 데이터가 정한다.** `observationEgoGiftDataList` 312종만 관측할 수 있다. 9283 상납된 시가처럼 테마팩 한정이면서 관측 불가인 기프트가 21종 있어, 기존 「9283을 관측해 충돌 해소」 테스트는 「9222(관측 가능)를 대신 관측해 5층을 비운다」로 바뀌었다.
- **관측 추천 순서**: 지정(사용자) → 구제(루트로 못 얻는 기프트; 관측 불가면 그 층을 혼자 점유한 관측 가능 기프트) → 유연성(단독 픽업 팩을 해제, 창이 좁은 팩부터). `assignPacks`는 최대 2회. 유연성 단계는 최적 팩 수가 정확히 1 줄기 때문에 재탐색 없이 배정을 편집한다.
- **대안 루트**는 `pack-conflict`가 있을 때만 계산한다(충돌 상황은 탐색이 작아 2~6ms). 두 개 이상 빼야 하는 조합은 각 변형이 자기 충돌을 그대로 보여 준다.
- **클리어 보상**은 `packs.json`을 건드리지 않고 기프트의 `clearRewardOf`와 `indexes.packsByGift` 덮어쓰기로만 연결한다(EXTREME 풀 == 범용 집합 불변식 유지).
- **팔레트 예외**: `--color-ok`/`--color-bad` 두 유채색은 아이콘 테두리에만 쓴다.
- **참고 카드**는 루트에 영향 주는 경고만 남긴다(`general-drop-not-guaranteed`, `condition-unmet`, `fusion-slots`는 표시하지 않음 — 아이콘 테두리와 인게임 정보로 충분).

## 남은 것

- 대안 루트는 기프트 **하나**만 뺀 변형만 만든다. 둘 이상 빼야 하는 조합은 변형 안의 충돌로만 드러난다.
- 관측 유연성 단계는 자리 3개를 모두 쓸 수 있다(별빛 270). 비용 브레이크가 필요하면 `rules.giftObservation`에 상수를 더한다.
- 인격 초상 자리는 두지 않았다(요청 범위 밖). 실제 이미지 연결은 R2 업로드 뒤 `VITE_ASSET_BASE` 설정으로.
- 993005의 정체, 히든 전투가 팩 선택과 무관한지는 인게임 확인이 필요하다.
- 출격 최대 7의 게임 내 근거·E.G.O 키워드·`includesSpecial`은 M7과 같다.
