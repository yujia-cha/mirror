# M21 — 아이콘 배지 · 키워드 색 · 선택 잠금 · 무대 정리

커밋: `M21: 키워드는 배지로·티어는 좌상 · 키워드 색 조정 · 포함/얽힘 선택 잠금 · 층 스트립 통일 · 근사 설명문 삭제`

## 무엇을 했나

사용자 지시 8가지.

1. **키워드·티어 자리 교체** — 키워드가 테두리에서 **우하 배지**로 내려오고, 티어가 **좌상**으로 올라갔다. 아이콘의 네 모서리가 이제 각각 하나씩만 말한다: 좌상 티어 · 우상 획득/실패 · 좌하 반드시 · 우하 키워드. 아이콘 테두리는 중립 회색 한 줄로 통일했다.
2. **키워드 색 조정** — 파열 보라 → **초록**, 호흡 청록 → **흰색**, 화상 → **더 주황**, 출혈 → **분홍 쪽 빨강**. 진동·침잠·충전은 지시에 없어 두었다. 화상이 주황으로 가면서 충전(`#f0a020`)과는 오히려 **멀어졌다**.
3. **물리 속성은 한 가지 잉크 + 모양** — 참격·관통·타격이 `--color-kw-attack` 하나를 쓰고 **마름모·원·사각**으로 갈린다. 어둠 모드에서는 순검정이 사라지므로 중성 회색으로 뒤집는다(이 저장소의 모든 토큰이 그렇게 한다). **범용은 배지를 그리지 않는다** — 446개 중 114개가 범용이라 회색 배지가 격자를 덮는다.
4. **근사 설명문 삭제** — 우측 「전체 루트」의 `search-capped` 설명 배너(`cappedBanner`)를 지웠다. 요약줄의 「근사 결과」 배지는 한 낱말짜리 표식이라 남겼다.
5. **얽힘은 이제 막는다** — 고른 목표와 재료가 겹치는 조합은 **선택 불가**다. M15에서는 경고였다(「재료를 두 번 주우면 둘 다 된다」). 사용자가 막아 달라고 해 규칙을 바꿨고, 이미 둘 다 담긴 저장본·공유 링크는 그대로 열리며 얽힘 표시(🔗)만 남는다.
6. **상위를 고르면 하위는 포함 처리** — 목표의 **재료 트리 전체**를 잠근다. 전에는 `upgradeOf`(같은 키워드 승급 사슬)만 잠갔기 때문에 데스페라도(관통)를 골라도 그 재료인 노이즈 섞인 무전기(침잠)가 계속 고를 수 있었다. 이미 골라 둔 재료는 상위를 고르는 순간 선택에서 빠진다.
7. **층 스트립 통일 · 점 삭제** — 1~5 / 6~10 / 11~15의 배경 구분(`bg-surface-2`·`bg-hatch`)을 없애 열다섯 칸을 한 모양으로 두고, 팩이 있음을 알리던 점을 지웠다. 팩 이름은 `title`·`aria-label`·`data-pack`에 그대로 있다.
8. **「다른 팩 입장」 → 「넘기기」** — 이 카드는 팩에 들어가는 게 아니라 이 층을 **넘기는** 동작(`next`)이라 이름이 동작과 어긋나 있었다.

## 핵심 규칙

- **아이콘의 네 모서리는 각각 하나만 말한다.** 색조를 쓰는 곳은 키워드 배지와 판정 링 둘뿐이라는 규칙은 그대로다.
- **물리 속성은 색이 아니라 모양으로 갈린다.** 셋 다 같은 잉크다.
- **고른 목표가 정리하는 기프트는 고를 수 없다.** 포함(재료 트리)이 얽힘보다 먼저 판정되고, 이미 고른 기프트는 잠그지 않는다(스스로 뺄 수 있어야 한다).
- **층 스트립 열다섯 칸은 같은 모양이다.** 띠도 점도 없다.

## 검증 로그

- `npm run check` 통과(320 tests; 새 테스트 7). `npm run build` 성공. lint 경고 1건(`PlanContext.tsx` react-refresh)은 이전부터 있던 것. 데이터 파이프라인은 건드리지 않아 `public/data`에 변경 없음.
- 브라우저(`vite preview` + playwright-core, 1280×900, 밝음·어둠 둘 다):
  - 배지 색이 토큰과 일치: 밝음 파열 `rgb(63,154,51)`·출혈 `rgb(224,51,95)`·화상 `#ec6b12`, 어둠 파열 `rgb(99,192,90)`·물리 `rgb(168,162,158)`. 호흡 흰 배지는 헤어라인 덕에 밝은 배경에서도 보인다(4× 확대 확인).
  - 진혼(화상) 둥근 사각 · 꿈을 꾸는 전기양(참격) 마름모 · 데스페라도(관통) 원 · 오늘의 표정(타격) 사각 · 깨진 안경(범용) 배지 없음. 티어는 전부 좌상.
  - 데스페라도를 고르면 노이즈 섞인 무전기 타일이 `data-block="included"`로 잠기고 버튼이 disabled, 제목이 「데스페라도 조합에 이미 포함됨」. 장관을 고르면 부동이 `entangled`로 잠긴다. 먼저 골라 둔 무전기는 데스페라도를 고르는 순간 선택에서 빠진다.
  - 층 스트립 15칸 전부 점 없음·띠 없음, 카드 문구 「넘기기」.
  - 콘솔 에러 0(양쪽 테마).

## 남은 것

- 얽힘을 막으면서 「재료를 두 번 주워 둘 다 만드는」 길은 UI에서 사라졌다. 되살리려면 목표별로 예외를 켜는 스위치가 필요하다.
- 배지는 9px(작은 아이콘 6px)이라 모양 구분이 20px 아이콘(노선도·칩)에서는 사실상 색만 남는다. 그 크기에서 티어를 감추는 규칙은 그대로다.
