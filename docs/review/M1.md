# M1 — 게임 데이터 파이프라인

커밋: `M1: 게임 데이터 파이프라인과 생성 데이터`

## 무엇을 했나

게임 클라이언트의 정적 데이터와 공식 로컬라이제이션을 내려받아, 플래너가 쓸 JSON 6개로 정규화했습니다. **위키를 긁지 않고 게임 데이터 자체를 근거로 삼습니다.**

```
data/raw (vendoring, 커밋됨)  ─┐
                               ├─ scripts/build-data.ts ─→ public/data/*.json
data/curated (사람이 작성)     ─┘            │
                                  scripts/validate-data.ts
```

## 읽는 순서

1. `src/core/schema.ts` — **여기가 제일 중요합니다.** 생성 데이터의 모양을 Zod로 정의하고 파이프라인·앱·테스트가 공유합니다.
2. `data/curated/rules.json` — 게임 상수. 코드에 박힌 상수는 없습니다.
3. `scripts/lib/derive.ts` — 층 제한·등급·인격 키워드 파생 규칙
4. `scripts/lib/parse-conditions.ts` — 조건부 기프트 문장 파서
5. `scripts/build-data.ts` — 조립
6. `scripts/validate-data.ts` — 불변식
7. `tests/generated-data.test.ts` — 실제 데이터에 대한 단정 33개

## 핵심 판단 세 가지

**1. 층 제한 해석.** `exceptionConditions[].selectableFloors`는 **0-기준**이고 `dungeonIdx`는 모드입니다(0=Normal, 1=Hard, 2=평행중첩, 3=EXTREME). dungeonIdx 2·3에 `selectableFloors`가 없으면 그 모드 전 구간입니다. 이 해석은 OpenLethe 서버 재구현의 `MdMapGen.RecreateThemes`(`act = floor/5+1`)와 일치합니다.

**2. 키워드 조건은 인격 태그가 아니라 스킬 보유로 센다.** 게임 문장이 "[X]를 부여하는 **공격 스킬을 보유한** 인격이 N인 이상"이라서, 인격 키워드를 `skill/personality-skill-*.json`의 `buffKeyword`에서 도출합니다. 표본 검증(LCB 이상=침잠, 남부 세븐 6과 이상=파열, 흑운회 와카슈=출혈 등)은 커뮤니티 데이터와 일치합니다.

**3. 범용/전용 분류의 교차 검증.** 전용 기프트가 없는 EXTREME 팩의 풀이 범용 기프트 집합(187개)과 **정확히 일치**합니다. 이를 `data:validate`의 불변식으로 넣어, 파생 규칙이 깨지면 빌드가 실패합니다.

## 봐 주셨으면 하는 점

1. **아는 기프트 5개를 골라 `public/data/gifts.json`에서 확인해 주세요.** 이름·키워드·등급·전용 팩·조건이 인게임과 같은지. (예: `jq '.[] | select(.id==9283)' public/data/gifts.json`)
2. **본인 덱 인격의 키워드**가 `public/data/identities.json`에서 맞게 나오는지. 틀리면 `data/curated/identity-keywords.json`으로 고칩니다.
3. 조건 파싱 스냅샷(39+19건)에 오탐이 없는지. `parse-conditions.test.ts`의 문장은 전부 게임 원문입니다.
4. 불변식 수치(팩 116·범용 187·기프트 446)가 앞으로 시즌이 바뀌어도 적절한 경보 역할을 할지.

## 알려진 한계

- **인격 10116**(LCE E.G.O:: 차원찢개 이상)은 로컬라이제이션에만 있고 정적 데이터에 없어 덱에 못 넣습니다. 업스트림이 데이터를 올리면 자동으로 들어옵니다.
- **특수 화상/출혈 등 변형**은 인격별로 판정하지 않습니다(`special: false` 고정). "및 특수 X" 형태 조건은 보정이 필요합니다.
- **미해석 조건 1건**(9795 떨어진 한 방울, `[BloodDinner]` 소모 스킬 조건)은 키워드·소속 어느 쪽도 아니라 `unparsed`로 남겨 UI가 원문을 보여 줍니다.
- `data/raw`가 6.9MB 커밋되어 있습니다. OpenLethe가 사라져도 빌드가 되도록 한 의도적 선택입니다.
