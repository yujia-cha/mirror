# M28 — 동작 검증 · 강조색 하나 · 무대 행동 우선 · 초성 검색

사용자 지시: 「1. 동작에 버그가 있는지 검증 (로직 외) 2. 디자인 및 가시성 직관적으로 개선 (시안 제작 후
반영 여부 결정) 3. 사용감 개선 방법 모색」

루트 계산(`src/core`)은 M23에서 완전 탐색까지 다듬었지만 **앱 동작(`src/app`)은 M12부터 규칙이 쌓이기만
했고 통째로 점검한 적이 없었다.** 그래서 이번 마일스톤은 ① 앱 동작 버그 ② 시안을 먼저 내고 고른 것만
구현 ③ 검색 품질 순으로 갔다.

사용자가 정한 것:

| 항목 | 결정 |
|---|---|
| 색 정책 | 회색 기조 유지 + **「지금 할 일」에만 쓰는 강조색 하나** |
| 변경 폭 | 부분 재구성 허용(패널/탭 구성 · 무대 · 층 스트립) |
| 주 환경 | **PC 듀얼 모니터 · 게임 옆 창** — 데스크톱 양쪽 패널 열린 상태가 1순위 |
| 버그 범위 | 상 + 중까지. 저심각은 이 문서의 「남은 것」으로 |
| 시안 반영 | **무대 「행동 우선」** · **층 스트립 ⓑ** · **초성 검색** 셋만 |

## 1. 동작 버그 — 재현 가능한 34건

세 갈래로 훑어 약 50건이 나왔고 상·중 34건을 네 커밋으로 고쳤다(`39bb9d2`·`1968cb4`·`35d219b`·`53657ad`).
묶음마다 회귀 테스트를 붙였다. 심한 것부터:

- **층 스트립으로 앞으로 걸어 나가면 정산이 통째로 빠졌다.** 표시하지 않은 목표가 실패로 기록되지 않아
  지나간 팩을 플래너가 공짜 공급으로 세고 「확보 1/1」이 런 내내 남았다. 정산을 `next()`에서 떼어
  `PlanContext.settleFor(floor)`로 올리고, 앞으로 갈 때만 정산한다.
- **마지막 층에서 팩에 입장하면 「다음 층」이 죽어 런이 끝나지 못했다.** `done`을 마지막 층에서 읽던 것을
  `runDoneFloor(lastFloor)` 자체로 옮겼다 — 건너뛴 마지막 층이 미방문처럼 보이던 것도 같이 사라진다.
- **「포함」 잠금이 상세 시트에서 뚫렸다.** 타일은 잠기는데 이름 버튼 뒤의 시트가 선택을 허용했다.
- **목표 토글 규칙이 화면마다 셋이었다** → `lib/goal-toggle.ts`의 `carriedBy` 하나로. 그전에는 잠기면서
  동시에 선택된, 칩의 ✕ 말고는 뺄 수 없는 목표가 만들어졌다.
- **`window.confirm`이 없거나 막힌 환경에서 확인 없이 전체 초기화가 실행됐다**(`&&` short-circuit) →
  앱이 그리는 `ConfirmDialog`.
- **깨진 `#s=` 링크가 페이지를 통째로 날렸다.** `lz-string`은 읽을 수 없는 페이로드에 **던진다** —
  `decodeShared`의 try가 `JSON.parse`만 감싸고 있었다. 브라우저 확인에서 나왔고 정적 분석으로는 못 봤다.
- **오버레이가 pointerdown에 조건 없이 닫혔다** → `useDismiss`의 모듈 스택. 드로어를 연 버튼으로 그
  드로어를 못 닫던 것, 시트 안 누름이 뒤의 패널을 닫던 것, Escape가 둘 다 닫던 것이 한 원인이었다.
- 제스처 견고성 넷(끌면서 길게 누르기, 창 밖에서 놓기, 두 번째 손가락, 칩 위 스크롤 死角),
  관측 슬롯 넷, 화면에 틀리게 나오던 글자 여섯(`TEX`, 가격 구간 라벨, 푸터의 언어, 복사 글의 `4F` …).

**main 병합 두 번**을 거쳤다. `#38`이 같은 오버레이 스택을 독립적으로 만들었고(합치면서 main에 없는 두
가지 — `aria-controls` 오프너 검사, `onDismiss`를 ref로 읽어 레이어가 렌더마다 다시 쌓이지 않게 하는 것 —
을 남겼다), `cb5d475`의 시즌 축은 **옛 런 로직을 `lastFloor`로 매개변수화해 위 두 버그를 시즌 형태로
되살려** 놓았다. 수정을 `runDoneFloor(lastFloor)` 위로 다시 표현하고 5층짜리 시즌 케이스를 테스트에 넣었다.
내 `reconcile`은 버리고 main의 `adoptSeason`에 보증 두 개(관측 ∩ 목표, 런 기록을 아는 id로 거르기)를 접었다.

## 2. 시안 — 여덟 장을 내고 멈췄다

캔버스: https://claude.ai/artifact/CQWAATgKa4ZcS8Y6FGpVvp

토큰 · 무대 현재 · 무대 A(행동 우선) · 무대 B(진행 머리글) · 층 스트립 3안 · 우측 패널 현재/시안 ·
다크. 강조색은 보라(1안)와 청록(2안)을 실측 대비와 함께 냈다. 사용자가 **무대 A · 스트립 ⓑ · 초성 검색**
셋을 골랐고, 나머지(진행 머리글 · 다음 팩 예고 · 목표 상주 · 노선도 가로 분기 부활 · 런 키보드 경로 ·
되돌리기 토스트)는 **구현하지 않았다.**

## 3. 구현

- **강조색 하나**(`--color-accent`): 라이트 `#5647c9`, 다크 `#a89ff5`. 쓰는 자리는 **추천 팩 카드**와
  **무대에 선 층 칸** 둘뿐이다. 키워드 배지·판정 링과 함께 팔레트에서 색조를 쓰는 세 번째이자 마지막 자리다.
- **무대 행동 우선**: 추천 팩만 카드(150px · accent 테두리 · 「추천」 배지 · accent 발 버튼)이고, 이 층에서
  나가는 나머지 길은 옆의 줄이다(`StagePackRow`·`SkipRow`). 그전에는 추천과 그냥 팩의 차이가 테두리 색
  한 겹이었고 「넘기기」 빈 카드가 같은 크기로 나란히 섰다. 당기기 제스처는 줄에도 그대로 붙는다.
- **층 스트립 ⓑ**: 무대에 선 칸만 accent. 루트 팩 밑줄(ⓒ)은 넣지 않았다.
- **초성 검색**(`lib/hangul.ts`): 질의가 전부 초성일 때만 초성 모드. 기프트·팩·인격 검색 셋이 같은
  `matchesQuery`를 쓴다. 덱 검색만 낱말 OR·소속·키워드까지 받던 비대칭이 줄었다.

자세한 규칙은 `docs/design/ui-redesign.md`의 「M28 추가 규칙」에 있다.

## 4. 검증

`npm run check` 통과(**391 tests**) · `npm run build` 성공 · `public/data` 변경 없음.

브라우저(`vite preview` + playwright-core, Chromium): 1440×900·400px × 라이트/다크 네 조합에서 콘솔 에러 0,
가로 넘침 0. 실측 대비:

| 자리 | 라이트 | 다크 |
|---|---|---|
| accent (배경 위) | 6.19:1 | 7.97:1 |
| accent 위 글자 | 6.69:1 | 7.45:1 |
| 아직 못 가는 층 칸 글자 | **5.02:1** (전 ≈3.0:1) | 5.71:1 |

시즌 축 병합 뒤로 밀려 있던 손 확인도 같은 실행에서 끝냈다 — 층 스트립 정산(`giftStatus` → `failed`),
마지막 층 입장 후 `done`, 앱 안 확인(취소하면 아무것도 안 바뀐다), 깨진 링크 알림(해시 유지·화면 살아 있음),
폰에서 페이지 위 시트의 Escape가 시트만 닫고 `body` 스크롤이 잠기는 것.

## 5. 남은 것

- `--color-kw-breath`(#ffffff)가 라이트의 `surface-3` 위에서 **1.26:1**, 1px 외곽선도 2.4:1이라 WCAG 1.4.11의
  3:1에 못 미친다. 이번에 손대지 않는 파일이라 미뤘다.
- 층 스트립에서 **앞으로 갈 때도 건너뜀을 되무르는** 동작(기록 손실은 없다).
- `PanelResizer`의 `pointerId`·포커스·`aria-valuetext` 잔가지, `role=tablist`/`radiogroup`의 방향키·
  roving tabindex.
- 세로 노선도의 카드 겹침과 좁은 패널에서의 음수 폭(재현 조건이 까다로워 **미확인**).
- `resetRun`이 UI에서 닿지 않는 것.
- **쓰이지 않는 가로 노선도 분기**(`MetroMap.tsx`의 `variant="horizontal"` + `stackBlocks`): 이번 시안에서
  되살리지 않기로 했으므로 다음에 지운다.
