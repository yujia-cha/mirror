# M20 — 탄환 키워드

커밋: `M20: 탄환(Bullet) — 인격 전용 키워드로 추가`

## 무엇을 했나

사용자 지시 하나: 「키워드에 탄환도 추가해줘」.

원본 데이터를 먼저 확인했고, 그 결과가 설계를 정했다.

- `BattleKeywords.json`의 `Bullet` = 「탄환」 / EN "Ammo". 특수 변형은 M16과 같은 규칙(설명에 「- 특수 탄환」 한 줄)으로 8종이 잡힌다(호표탄·맹호표탄·포자탄[기본]·포자탄[산탄]·LCA 균열탄·탄환 - 고독·탄환 - 로직 아틀리에·작열 추진탄).
- **탄환은 기프트 키워드가 아니다.** `EgoGiftCategory.json`에 없고, 탄환 기프트 0개, 탄환 키워드 팩 0개(1401~1414는 7키워드 × 2), 시작 기프트 풀에도 없다(10개 = 7키워드 + 참격·관통·타격).
- 그래서 `STATUS_KEYWORDS`에 그냥 넣으면 조용히 깨진다: `enums.keywords`의 이름이 원본 id "Ammo"로 폴백하고, 아이템 키워드 필터와 시작 키워드 선택에 아무것도 안 걸리는 항목이 생기며, `dominantKeyword`가 탄환을 자동 시작 키워드로 골라 **시작 기프트를 없앤다**.

그래서 탄환은 **인격 전용 키워드**로 넣었다.

1. **스키마** — `IDENTITY_KEYWORDS = [...STATUS_KEYWORDS, 'Bullet']`를 새로 두고 `Identity.keywords`만 이 열쇠를 쓴다. 조건·팩 친화·기프트 키워드·시작 풀은 전부 기존 `StatusKeyword`/`Keyword` 그대로다. 표시 이름은 `enums.identityOnlyKeywords`(지금은 탄환 하나)로 따로 내보내고, 이름은 `BattleKeywords.json`에서 읽는다(코드에 박지 않는다).
2. **도출** — 탄환은 적에게 부여하는 상태가 아니라 스킬이 **소모하는 자원**이라 `buffKeyword`로 나오지 않는다(원본에서 기본 공격 스킬의 `buffKeyword: "Bullet"`은 0건). 대신 스크립트가 요구 버프를 `UseBullet[necessary:Bullet:1]`·`[optional:AccelBullet:1]` 꼴로 적는다. 이 **요구 토큰**을 읽고, 토큰 id에 `Bullet`이 들어 있으면 탄환으로 센다(게임의 탄환 계열 id는 전부 `Bullet`을 포함한다). 그 id가 특수 변형이면 `specialSkills`, 아니면 `skills`다. 결과 13명.
3. **UI** — 인격 칩에 「탄환」·「탄환(특수)」·「특수 탄환」이 뜬다. 툴팁만 소모형 문구를 쓴다(「탄환 소모 공격 스킬 보유」) — 다른 키워드는 「부여」가 맞고 탄환은 아니다. 덱 요약 칩과 인격 검색도 탄환을 그대로 받는다.
4. **안전장치** — `dominantKeyword`가 상태 키워드만 고르도록 막고(시작 풀이 있는 것들), `data:validate`에 불변식 3개를 넣었다: 탄환 인격 0명이면 경고(요구 토큰 문법 변화 감지), `identityOnlyKeywords`에 진짜 이름이 없으면 오류, 모든 상태 키워드에 시작 풀이 있어야 한다.

## 읽는 순서

1. `src/core/schema.ts`(`IDENTITY_KEYWORDS`·`identityOnlyKeywords`) → `src/core/types.ts` → `src/core/deck.ts`(`dominantKeyword` 필터).
2. `scripts/lib/derive.ts`(`SKILL_REQUIREMENT`·`AMMO_BUFF_ID`·`keywordsInSkill`) · `scripts/lib/raw.ts`(`readSpecialVariants`에 탄환 추가, `readBattleKeywordNames`).
3. `scripts/build-data.ts`(enums) · `scripts/validate-data.ts`(불변식).
4. `src/app/format.ts`(`keywordName` 폴백, `identityKeywordLabel`의 소모형 분기) · `src/app/i18n.ts`.
5. 테스트: `scripts/lib/derive.test.ts`, `tests/generated-data.test.ts`, `src/core/__tests__/planner.test.ts`, `src/app/__tests__/app.test.tsx`.

## 핵심 규칙

- **탄환은 기프트 키워드가 아니다.** `KEYWORDS`에 넣지 않는다. 아이템 키워드 필터·시작 키워드 선택·트래커의 키워드 상위 기프트 7종은 `enums.keywords`만 보므로 그대로다.
- **탄환은 소모한다.** 도출도 표시 문구도 「부여」가 아니라 「소모」다.
- **시작 키워드는 상태 키워드뿐이다.** 시작 기프트 풀이 있는 키워드만 자동 선택 후보가 된다.

## 남은 것

- `BulletLament`(엄숙한 애도)·`AccelBullet`(거미집 엄지 아비)은 `BattleKeywords.json`에 항목이 없어 특수 여부를 알 수 없다. 지금은 기본 탄환으로 센다. 로컬라이즈가 추가되면 자동으로 특수로 넘어간다.
- 시즌이 바뀌어 탄환 기프트·탄환 키워드 팩이 생기면 그때는 `KEYWORDS`로 승격해야 한다. `EgoGiftCategory.json`에 탄환 항목이 생기는 것이 그 신호다.
