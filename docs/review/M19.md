# M19 — 초기화 통합 · 아이템 패널 재편(관측 슬롯·포기 삭제·거의 활성 삭제·루트 설정 흡수) · 텍스트 다이어트 · 키워드 테두리

커밋: `M19: 헤더 초기화 하나로 통합 · 아이템 탭 재편(관측 슬롯·칩→시트·포기=선택 해제·루트 설정 흡수) · 난이도/안내 텍스트 삭제 · 키워드 테두리`

## 무엇을 했나

사용자 지시 12건(도중 추가 1건 포함).

1. **초기화가 안 되던 이유** — 「옵션 초기화」는 `options`만, 「새 런」은 `run`만 지웠는데 `planInputFor`가 매번 `run`(방문 팩·획득 상태·현재 층)으로 `options`를 덮어쓰므로 런이 끝난 뒤 옵션을 초기화해도 화면이 그대로였다. 게다가 `App.tsx`의 기본 덱 시딩은 최초 1회라 덱을 비우면 새로고침 전까지 빈 덱이었다. → 헤더(링크 복사 **왼쪽**)에 **초기화** 버튼 하나(`RotateCcw`, `window.confirm`)를 두고 `store.resetAll(deck, deployedDefault)`로 덱(LCB 12인)·출전·아이템·우선순위·조합 목표·옵션·런을 한 번에 되돌린다. `ui`·`lang`·`dark`는 남는다. 「새 런」(무대 종료 카드·루트 설정)·「옵션 초기화」·`resetOptions`는 삭제.
2. **다른 팩 목록** — 각 행에 팩 이름 아래 그 팩의 전용 기프트 아이콘(무대 카드와 같은 `ExclusiveIcons`, 최대 5 + 「+n」, 원하는 것은 링). 「원함 N」 텍스트 삭제, 행 폭 240px.
3. **칩 클릭 → 상세 시트** — 아이템 탭 선택 칩의 이름을 누르면 `GiftDetailSheet`가 열린다(`jumpTo`·스크롤 이동 삭제).
4. **포기 삭제** — `Priority = 'must' | 'normal'`. 「포기」는 선택 해제(`removeWanted`): 미해결 카드의 행 버튼, 대안 탭의 「이 기프트 선택 해제」 모두. 칩의 별·눈 버튼, 포기 목록(`skipped`), `skippedGifts`, 텍스트 복사의 「포기:」 줄 삭제. 상세 시트의 우선순위 버튼은 보통 ↔ 반드시 토글.
5. **관측 슬롯** — 검색·필터 아래, 선택 칩 위에 `ObserveSlots`(`rules.giftObservation.max` = 3칸). 빈 칸 「+」→ 팝오버에 관측 가능한 선택 기프트 목록(관측 불가·이미 지정은 제외), 채운 칸은 아이콘·이름·✕. **칩 드래그**(`useChipDrag`: 포인터 이벤트, 8px 넘게 움직여야 시작, 고스트는 `createPortal`, 놓은 뒤 클릭 한 번 삼킴)로도 지정하고, 찬 칸에 놓으면 교체한다. 관측 불가 칩을 놓으면 무시.
6. **루트 설정 탭 삭제** — 시작 키워드 `<select>`와 포함·포기한 팩 목록을 `RouteOptions` 카드로 아이템 탭 하단에 옮겼다. `LeftTab = 'deck' | 'gifts'`, `sanitizeUi`가 옛 `'settings'`를 `'gifts'`로 접는다. 관측 목록·「항상 1~15층 · Hard로 계획합니다」 삭제.
7. **거의 활성 삭제** — `GiftGroup = 'active' | 'other'`. 조건이 하나라도 모자라면 「기타」.
8. **노선도 문구 삭제** — 세그먼트 제목(「N층 고정」「N~M층 중 한 층」「추천 N」「N팩 · 어느 층이든」), 범례 전체, 띠 라벨(`Hard`·`평행중첩`·`EXTREME`), 관측 타일의 「지정/추천」 알약(눈 배지 채움 + `data-pinned`로 대신). `metro.ts`의 `SegmentPack.reason`·`suggestedOrder` 삭제. 텍스트 복사는 「2~3F: …」.
9. **난이도 텍스트 삭제** — 무대 헤더 띠 라벨, 팩 시트 「Hard 4~5」→「4~5층」(Normal 구간은 쓰지 않음), 기프트 시트 「Hard 전용」, `MODE_LABEL`·`bandOf`·`optionBand*`·`mode*` 키.
10. **안내문 삭제** — `stagePullHint`·`stageHistoryHint`·`stageBackHint`·`stageGotHint`·`stageNextHint`·`stageOtherEntryHint`·`routeGoalsHint`·`trackerHint`·`routeEmptyHint`·`conflictHint`·`deckEmptyHint`·`giftsObserveHint`. 「이 층에 계획된 팩이 없습니다」→「계획된 팩 없음」, 덱 검색 도움말 「{n}명」.
11. **키워드·공격 유형 테두리**(추가 요청) — `GiftIcon` 테두리를 `gift.keyword`로 그린다: 화상·열상·진동·파열·침잠·호흡·충전은 색(`--color-kw-*`, 다크 모드는 밝은 값), 참격 파선·관통 점선·타격 이중선, 없음은 회색 실선. 조건 판정(충족/미충족/판정 불가)은 바깥 링(`ring-ok`/`ring-bad`/회색)으로 옮겼다. `data-keyword` 속성 추가.

## 핵심 규칙

- **초기화는 하나**: `resetAll`만이 덱·아이템·옵션·런을 함께 되돌린다. 부분 초기화 버튼을 다시 만들지 않는다(런이 옵션을 덮어쓰므로 부분 초기화는 화면에 보이지 않는다).
- **포기는 상태가 아니다**: 원하지 않으면 선택에서 뺀다. `PriorityMap`은 `'must'`만 담는다.
- **관측은 슬롯**: 지정 경로는 「+」 목록·칩 드래그·상세 시트의 관측 버튼 셋이고 전부 `toggleObserved`(한도·관측 가능·선택 여부 검사)를 거친다. 찬 칸에 놓을 때만 `setOptions({ observedGifts })`로 교체한다.
- **글자 대신 모양**: 난이도·세그먼트·범례·조작 안내를 텍스트로 쓰지 않는다. 노선도는 채움/점선/굵기, 아이콘은 테두리(키워드)+링(판정), 관측 타일은 눈 배지 채움으로 말한다.

## 남은 것

- 관측 슬롯 드래그는 포인터 이벤트만 쓴다(키보드로는 「+」 목록). 터치에서 칩을 길게 잡으면 브라우저 텍스트 선택이 뜰 수 있어 `select-none`·`touch-action: none`을 두었지만 실기기 확인은 남았다.
- `ExclusiveIcons`는 최대 5개까지만 보이고 나머지는 「+n」이다. 팩 시트가 전체를 보여 준다.
