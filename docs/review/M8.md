# M8 — 페이지 테스트로 찾은 버그 수정과 디자인 개선

커밋: `M8a: 페이지 테스트로 찾은 버그 수정·디자인 개선`, `M8b: 문서`

## 무엇을 했나

M7 구현을 Chromium(playwright-core)으로 실제로 눌러 보며 1280×900·400×860에서 세 단계, 다크·영문, 15층 계획, Normal 상태의 미해결, 검색·인격 선택 팝오버, 공유 링크 왕복, 텍스트 복사, 빈 상태, 로딩 실패를 확인했습니다. 재현된 버그 11개와 눈에 띈 디자인 문제 10개를 고쳤습니다. 코어는 층 창(`window`) 계산 한 곳만 바뀌었고 데이터 생성물은 그대로입니다.

## 읽는 순서

1. `src/core/index.ts` `windowFor` — 창을 「다른 배정 고정」이 아니라 **공동 가능성**(이분 매칭)으로 계산
2. `src/app/App.tsx`, `src/app/store.ts` — 공유 해시를 한 번만 소비하고 URL에서 지움, 받는 사람은 3단계로
3. `src/app/lib/timetable.ts`, `src/app/components/Timetable.tsx` — 열 정의 수정, 범위 밖 열 1개, 자유 층 병합, 시작 칸
4. `src/app/steps/GiftsStep.tsx` — 서브행 체크박스·획득 배지, 행 카운터, 트레이 칩 → 행 이동
5. `src/app/steps/DeckStep.tsx`, `src/app/lib/useDismiss.ts` — 검색 콤보박스 키보드·바깥 클릭, 인격 선택 팝오버
6. `src/app/steps/RouteStep.tsx`, `src/app/lib/unresolved-actions.ts` — 조건 판정 줄바꿈·판정 불가 아이콘, 미해결 조치 합치기, 층 확장 계산
7. `src/app/lib/plan-text.ts`, `src/app/condition-text.ts`(`josa`) — 복사 문구 현지화, 조사
8. 테스트: `src/app/__tests__/app.test.tsx`, `src/app/__tests__/timetable.test.ts`, `src/core/__tests__/planner.test.ts`(floor windows)

## 발견과 조치

| # | 증상 | 조치 |
|---|---|---|
| B1 | 링크 복사 뒤 새로고침하면 그 뒤에 바꾼 내용이 사라짐 (`#s=`가 URL에 남아 마운트마다 재적용) | 해시는 마운트 때 한 번 읽고 `replaceState`로 지움. `share()`는 클립보드만. 받는 사람은 기프트가 있으면 3단계로 |
| B2 | 15층 계획에서 시간표 열 폭 붕괴 (`repeat(0, 28px)` 무효 CSS) | 열 정의를 조건부로 조립, 범위 밖은 44px 열 하나 |
| B3 | 하위(계승) 기프트를 단독으로 고를 수 없음 | 서브행에 체크박스. 상위 선택 시 잠김 + 「포함」 |
| B4 | 복사 텍스트에 `Combustion`, `(hard)` | 키워드·모드 라벨 콜백으로 현지화 |
| B5 | 「기타 358」 vs 「446개 중」 | 가상 목록 라벨을 행 수 기준으로 |
| B6 | 검색 결과에 키보드 조작 없음, Escape·바깥 클릭에도 안 닫힘 | `role=combobox` + ↑↓ Home End Enter Escape, `useDismiss` |
| B7 | 조건 문장이 한 줄로 잘림, 「을(를)」 | 줄바꿈 허용, `josa()`로 받침 판별 |
| B8 | 판정 불가가 ✕로 보여 미충족처럼 읽힘 | 물음표 아이콘 + `aria-label` 판정 불가 |
| B9 | 「10층까지 계획」이 5층으로 충분한 경우에도 Hard를 강제 | 팩이 처음 나오는 층의 밴드 끝까지만, 5층 이하면 Hard 유지 안 함 |
| B10 | 시작 기프트가 없으면 시작 칸이 빈 칸 | 시작 키워드 표시 |
| B11 | 펼친 행 높이 추정치가 작음 | 80px, 펼친 행이 있으면 overscan 10 |
| D1 | 범위 밖 열이 세로 글자로 공간 낭비 | 열 하나(`6~` 헤더, 「범위 밖」 가로 2줄) |
| D2 | 자유 층마다 「자유」 반복, 모바일 15층은 580px | 연속 자유 층을 한 셀/40px 행으로 「자유 · 6~15층」 |
| D3 | 인격 선택 패널이 카드를 400px로 늘림 | `sm:` 이상에서 absolute 팝오버, Escape·바깥 클릭 |
| D4 | 서브행이 상위 이름을 반복, 하위 획득 종류 안 보임 | `→ 이름 · T · 획득 배지 · Hard`, 상위 이름은 title |
| D5 | 같은 조치 버튼이 행마다 반복 | 공유 조치는 카드 헤더에 한 개 |
| D6 | 접힌 「기타」 안의 선택 항목이 안 보임 | 헤더에 「선택 n」 배지, 트레이 칩 클릭 → 행으로 스크롤(기타 자동 펼침) |
| D7 | 「옵션 초기화」가 select 옆에 붙음 | ghost 버튼, 옵션 바 우측 끝 |
| D8 | 모바일 기프트 행에 수치 없음 | `<sm`에서 `6/5` 수치 |
| D9 | 기어오는 심연(Hard 3~4)·변하지 않는(Hard 4~5)에서 앞의 것이 「고정」으로 표시 | 공동 가능성으로 계산 → `{3,4}`, `{4,5}` |
| D10 | 덱 칩 「화상 10」 | 데이터가 맞음(attributeList 10개). 칩 title로 설명 |

## 남은 것

- 창(`window`)은 여전히 「연속 구간」만 남깁니다. 가능한 층이 {3, 5}처럼 끊기면 배정 층을 포함한 구간만 보입니다.
- 트레이 칩으로 「기타」 안의 행으로 이동할 때 가상 목록은 오프셋 계산으로 스크롤하므로 펼친 행이 있으면 몇 px 어긋날 수 있습니다.
- 출격 최대 7의 게임 내 근거, E.G.O 키워드 데이터, `includesSpecial`은 M7과 같습니다.
