# M14 — 당겨서 입장

커밋: `M14a: 당겨서 입장 — 팩 카드(이미지·제목·전용 기프트), 카드 영역(돌아가기/다음 층), 다른 팩 입장`, `M14b: 검증·문서 — 버튼에서 시작하는 당기기, 시트 위치, 프로브`

시안: https://claude.ai/code/artifact/25ce110b-c78a-490a-ae16-4cd851baaa4b (아트보드 A~F). 구현은 시안을 그대로 따른다.

## 무엇을 했나

M13의 드롭 존과 고스트를 버리고 **카드 자체를 당긴다**. 팩 카드는 팩 이미지 → 제목 → 그 팩에서만 나오는 기프트 아이콘(목표는 링) → 하단 「입장 ⌄⌄」로 서고, 아래로 72px 넘게 당긴 채 놓으면 입장한다. 입장하면 카드 행 자리에 **카드 영역**이 열려 팩은 왼쪽, 전용 기프트 타일은 오른쪽에 나온다. 영역 위 핸들 「⌃⌃ 돌아가기」(또는 영역을 위로 밀기)는 방문을 취소하고 **그 팩에서 표시한 기프트를 초기화**한 뒤 팩 선택으로 돌아가며 영역은 접혀 사라진다. 아래 핸들 「⌄⌄ 다음 층」(또는 아래로 당기기)은 M13처럼 표시하지 않은 목표를 실패로 기록하고 다음 층으로 간다. 행 끝의 점선 카드 「다른 팩 입장」을 당기면 기록 없이 다음 층이다(플래너 의미로는 건너뜀).

## 읽는 순서

1. `src/app/lib/usePullGesture.ts` — 포인터 이벤트 당기기: 세로 8px 넘게 움직여야 시작(가로는 스크롤), 허용하지 않는 방향은 0.3배 저항, 놓을 때 72px 넘으면 `onCommit(dir)`, `pullStyle()`은 쉴 때 transform을 두지 않는다(안의 fixed 시트가 absolute가 되지 않게). 버튼에서 시작할 수 있고(핸들·카드 하단이 버튼) 포인터 캡처는 쓰지 않으며, 커밋 직후 브라우저가 쏘는 click 하나를 삼킨다(요소가 포인터를 따라 움직여 mouseup이 같은 버튼 위에서 나므로).
2. `src/app/store.ts` — `unvisitPack(packId, { reset })`: 방문 취소 + `reset` 기프트의 상태(got·failed) 삭제. `src/app/shell/PlanContext.tsx` — `leave(packId)` = `unvisitPack(packId, { reset: exclusivesOf(packId) })`.
3. `src/app/stage/EnterablePacks.tsx` — `StagePackCard`(당기기, 제목 버튼은 시트를 부모에게 요청), `OtherEntryCard`, `OtherPacks`.
4. `src/app/stage/EnteredPack.tsx` — `PackArea`: `grid-template-rows 0fr → 1fr` 200ms로 열리고, `closing`이면 반대로. 위/아래 핸들 버튼 + 영역 전체 양방향 당기기.
5. `src/app/stage/RunStage.tsx` — 카드 행(줄바꿈, 가로 스크롤 없음) + 「다른 팩 입장」 + 팩 시트(카드 밖에서 렌더) ; 돌아가기 직후 200ms 동안 `pack-area-closing`을 남겨 접히는 전환.
6. 테스트: `app.test.tsx` 「RunStage」 — 당김 임계 미달 복귀·저항·버튼에서 시작·핸들 위 click 중복 방지·빈 카드·영역 아래(자동 실패)/위(초기화·후퇴); 「run store」 reset.

## 핵심 규칙

- **당기기 = 버튼과 같은 동작.** 카드 하단 「입장」, 영역의 「돌아가기」「다음 층」, 빈 카드의 「다음 층」은 모두 버튼이기도 하다. 키보드·보조기기는 버튼으로 같은 일을 한다.
- **돌아가기는 초기화다.** 그 팩의 전용 기프트(전용 ∪ 클리어 보상)에 기록된 상태를 지운다. 추적기나 다른 팩에서 표시한 것은 건드리지 않는다. 프런티어 후퇴 규칙은 M13 그대로.
- **다른 팩 입장 = 건너뜀.** 방문 기록 없이 `nextFloor`. 헤더의 「입장하지 않음 ›」과 같은 동작.
- 폰에서 카드·영역은 `touch-action: pan-x`라 세로 터치는 당기기로 간다. 카드 행은 줄바꿈이므로 가로 스크롤은 없다.

## 남은 것

- 위로 밀 때 영역 윗부분이 고정 헤더 아래로 들어간다(제스처 중에만). 상단 핸들을 헤더 아래에서 멈추게 하거나 이동량을 줄일 수 있다.
- 폰에서 카드·영역 위에서는 세로 스크롤이 막힌다(`pan-x`). 카드가 화면을 많이 차지하면 페이지 스크롤이 불편할 수 있다. 여백에서 스크롤하거나 카드 밖을 잡아야 한다.
- 「입장하지 않음 ›」(헤더)과 「다른 팩 입장」(빈 카드)은 같은 동작이다. 문구를 하나로 맞추는 편이 낫다.
