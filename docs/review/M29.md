# M29 — 무대의 글자 덜기 · 전체 루트는 팩만

사용자 지시(M28 배포 뒤 화면을 보고): 「1. 중앙 부분 팩 부분에서 "추천", "포함 n층", "n층에 입장"
텍스트는 삭제 2. 추천 팩 이외의 팩들은 기존 표시로 되돌리기 3. 우측 패널 전체 루트에서 팩만 표시하고
아이템은 표시하지 않음 4. 우측 패널 전체 루트에서 조건 판정 부분은 없앰 5. 시작 키워드와 관측 기프트
부분을 분리해서 표시」

물어서 정한 것: **추천 팩의 강조 자체를 없앤다**(순서로만 앞에 선다) · **「넘기기」도 점선 카드로**
되돌린다 · 시작과 관측은 **두 줄로** 나눈다.

## 0. M28을 한 마일스톤 만에 되돌린 이유

M28의 무대 「행동 우선」은 시안에서 고른 것이고 대비 실측까지 붙여 넣었지만, **게임 옆에 띄워 놓고
실제로 쓰니 과했다.** 무대가 묻는 것은 「어느 팩에 들어갈까」 하나이고, 계획이 고른 팩은
`enterablePacks`의 정렬로 이미 맨 앞에 선다. 그 위에 얹힌 accent 테두리·「추천」 배지·팩 상태 배지는
읽을 것만 늘렸다. 시안이 판단을 대신해 주지 못하는 종류의 것이었다 — 정지 화면에서는 「추천이 눈에
띄는가」가 좋아 보이지만, 런을 도는 동안에는 이미 아는 것을 매 층 다시 읽게 된다.

되돌린 것은 **레이아웃과 색**뿐이다. M28의 나머지(동작 버그 34건, 초성 검색, 층 스트립의 선 칸
강조와 비활성 칸 대비 5.02:1)는 그대로 있다.

## 1. 무대

- 루트 팩도 「넘기기」도 M28 이전의 **같은 128px 카드**다(`StagePackCard` + `OtherEntryCard` 복원,
  `StagePackRow`·`SkipRow` 삭제).
- 카드 머리의 **배지 슬롯을 통째로 지웠다** — 「추천」과 `PackStateBadge`(「포함 · N층」·「포함 지정」·
  「방문 · N층」…) 둘 다. 팩의 사정은 이름을 눌러 여는 팩 시트가 말한다.
- 입장한 팩 영역의 **「N층에 입장」**도 지웠다. 팩 시트의 같은 문장은 「입장 취소」 버튼이 무엇을
  취소하는지 설명하므로 남는다 — 그래서 `stageEntered` 키는 남고 `stageRecommended`만 지웠다.
- **accent가 무대에서 빠졌다.** 이제 팔레트의 색조는 키워드 배지 · 판정 링 · **층 스트립의 선 칸**
  셋뿐이다.

## 2. 우측 「전체 루트」

- **노선도는 팩만**: 블록에서 기프트 아이콘을 뺐다. 세로 배치의 블록 높이는 층 span에서 오므로
  기하학은 그대로다.
- **조건 판정 카드 삭제**: 판정은 아이템 격자 타일의 링과 기프트 상세 시트가 말한다. `conditions`
  자체는 계속 계산되고 `PlanContext`의 `judgements`·`giftTitle`이 그대로 쓴다.
- **시작 / 관측 두 줄**: `start-cell` 안이 `start-line`과 `observed-line`으로 갈렸다.

## 3. 테스트

- 무대의 카드/줄 테스트 둘을 하나로 합쳤다 — 「루트 팩이 모두 같은 카드이고 배지 글자가 없다」.
  목표 다섯으로 한 층에 루트 팩 둘이 서는 시나리오는 그대로 쓴다.
- 조건 판정 테스트 둘은 우측 패널에서 **아이템 격자 타일**로 옮겼다(`data-judgement`가 여전히
  met/unmet/unknown을 말한다). 「반드시」 별 배지 테스트는 **목표 패널 타일**로 옮겼다.
- 새 회귀 둘: 노선도 블록에 `gift-icon`이 없다 · `start-cell`이 두 줄로 갈린다.

## 4. 검증

`npm run check` 통과(**392 tests**) · `npm run build` 성공 · `public/data` 변경 없음.

브라우저(`vite preview` + playwright-core): 1440×900·400px × 라이트/다크 네 조합에서 콘솔 에러 0,
가로 넘침 0. 카드 폭이 모두 128px이고 「추천」·「포함」·「N층에 입장」이 어디에도 없으며, 노선도 블록의
기프트 아이콘 수가 0, 조건 판정 카드가 없고, 관측이 있는 계획에서 「시작 파열」 줄과 「관측 · 깨진
안경」 줄이 위아래로 갈리는 것을 확인했다.
