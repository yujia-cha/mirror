# M25 — 인격 데이터가 계속 늦던 문제: 출처 교체 · 자동 백필 · 합집합 검증

커밋: `data: 출처를 살아 있는 것으로 교체 · 정적 데이터에 없는 인격 자동 백필`

M24에서 10116 「차원찢개」 하나를 손으로 백필했는데, 곧바로 **10616 「동부 섕크 협회 3과」 홍루**가 또 없는 것이 드러났다. 사용자 지시: 「비교적 최신 인격들의 데이터가 없다, 앞으로를 대비한 방법을 세워라. 근본 해결책은 공식 데이터 또는 반영이 빠른 데이터를 찾는 것이다.」

## 1. 진단 — 출처 두 곳이 서로 다른 이유로 죽어 있었다

| 출처 | 실측 |
|---|---|
| OpenLethe `static-data` | 커밋이 2026-07-25 「init」 **하나뿐**. 갱신 루프가 없는 일회성 캡처다. ref를 계속 당겨도 영원히 안 바뀐다 |
| LocalizeLimbusCompany | 「Auto RAW Update」가 1~2주마다 돌았는데 **2026-07-23 이후 멈춤**(8월 커밋 2개) |

그래서 10116은 현지화에만 있었고, 10616은 **양쪽 모두에 없었다**.

**그리고 M24의 검증은 이걸 원리적으로 못 잡았다.** 「현지화에는 있는데 정적에 없는」 경우만 봤기 때문에, 둘 다 늦으면 침묵했다. 사각지대가 있다는 것을 사용자 제보로 알았다는 것 자체가 검증 실패다.

## 2. 근본 해결 — 살아 있는 출처를 찾았다

공개된 **무인증 공식 경로는 없다**. Project Moon CDN은 게임 설치본에서 뽑은 빌드별 토큰이 필요하고 거기 있는 것은 현지화뿐이며(StaticData는 클라이언트 번들 안), 게임 서버 API에도 데이터 엔드포인트가 없다. 실용적인 길은 추출물 미러뿐이고, 그중 살아 있는 둘을 찾아 **실제 내용을 확인**했다.

| 출처 | 갱신 | 10116 | 10616 |
|---|---|---|---|
| `x1bViolet/Limbus-Localization-Files` | 주 1회, **패치 당일** (`20.08.2026 Update [Cinq Assoc. East Section 3 Hong Lu]`) | ✅ | ✅ |
| `eldritchtools/limbus-assets` | 거의 매일 (`meta.json` 2026-09-14) | ✅ | ✅ |

**현지화 교체는 완전한 드롭인이었다.** 파일명·스키마가 동일해 파서를 한 줄도 안 고쳤고, 교체 후 `public/data`에서 **`meta.json` 외에는 한 바이트도 바뀌지 않았다** — 같은 데이터의 더 신선한 복사본이라는 가장 강한 증거다.

언어가 폴더가 아니라 브랜치(`Korean`/`English`)라 lock이 **언어별 ref·sha**를 받도록 넓혔다. `localPrefix`는 그대로라 파일은 여전히 `data/raw/localize/KR/…`에 떨어진다.

## 3. 자동 백필 — 손으로 적을 일이 사라졌다

정적 레코드가 없는 인격을 세 출처를 합쳐 조립한다(`scripts/lib/derived-source.ts`).

| 필드 | 출처 |
|---|---|
| 이름 | KR/EN 현지화 (기존 경로 그대로) |
| **공격 스킬 목록** | eldritchtools `skillTypes[].id` — **휴리스틱 대신 데이터**. `deriveIdentityKeywordsFromText`가 목록을 받도록 인자를 하나 늘렸다 |
| 키워드 | KR 스킬 원문 (M24의 도출기를 **수정 없이**) |
| 죄악·공격 유형·등급·시즌 | eldritchtools |
| 소속 | `tags` → 영문 표시명 역매핑. `readFactionNames('EN')`을 뒤집으므로 표가 아니라 데이터다(어긋나는 `L Corp.` 하나만 별칭) |

M24에서 근거가 없어 **비워 뒀던 필드가 전부 채워졌다**:

| | M24 (수기) | M25 (자동) |
|---|---|---|
| 10116 소속 | `[]` | `LIMBUS_COMPANY`, `LIMBUS_COMPANY_LCE` |
| 10116 죄악·공격 유형 | `[]` | 탐식·오만·질투 / 참격 |
| 10616 | 아예 없음 | 화상·호흡, `CINQ`, 분노·우울·오만 / 관통 |

덤으로 M24에서 「추정이라 적지 않는다」고 남겨 둔 LCE 소속 패턴이 실제 데이터로 확인됐고, rank 3 추정도 맞았다.

**우선순위는 정적 > 자동 백필 > 수기**이고, 아래층이 위층을 가리면 빌드가 멈춘다. 실제로 이 가드가 M24의 수기 항목을 잡아냈다 — 「10116 is now covered by the derived source」로 멈춰서 지웠다.

키워드만은 **KR 원문 값을 쓴다**. eldritchtools의 `skillKeywordList`는 179명 중 10명에서 우리 정적 도출보다 **덜 알기** 때문에 진실이 아니라 교차검증용이다. 10616에서는 두 독립 출처가 **일치**했다(KR 원문 → 화상·호흡 = `["Burn","Poise"]`).

## 4. 검증이 사각지대를 없앴다

1. **명부는 모든 출처의 합집합**이다. 어느 출처든 아는 재직 인격을 안 내보내면 에러이고, 메시지가 **어느 출처가 아는지** 말한다
2. **신선도 경고** — 파생 미러의 `meta.json` 시각이 우리 `fetchedAt`보다 14일 이상 앞서면 경고. vendoring 복사본이 낡는 것은 본질적으로 조용한 고장이라 데이터 자체가 말하게 만들었다
3. **키워드 교차검증** — 우리 값과 파생 미러가 어긋난 인격이 예산(15, 실측 11)을 넘으면 경고. 도출이 깨지면 여기서 먼저 보인다

가드가 실제로 도는지 손으로 확인했다:
- 파생 미러에서 10616을 지워도 **현지화가 아는 id라 여전히 에러** → 합집합이 작동한다
- `meta.json` 시각을 미래로 바꾸면 신선도 경고
- 수기 항목이 자동 백필과 겹치면 빌드 실패

## 5. 검증

`npm run check` 통과(348 테스트). `data:build` 두 번 돌려 출력 동일. 실제 브라우저에서 덱 검색 「섕크」 → 「홍루 · 동부 섕크 협회 3과 · 3성」이 나오고 슬롯 칩이 **호흡 · 화상**으로 읽힌다.

## 6. 남은 것 — 읽어야 할 위험

> **OpenLethe가 얼어 있다.** 거울 던전 팩·기프트·층·조합이 전부 거기서 오므로, **거울 던전 8이 오면 인격이 아니라 앱 전체가 멈춘다.** eldritchtools에 `md_theme_packs.json`·`md_floor_packs.json`·`gifts.json`이 있어 옮길 길은 있지만 파생 스키마라 어댑터가 필요하다. **시즌이 바뀌기 전에** 손봐야 한다.

- 수기 백필(`data/curated/identities.json`)은 이제 비어 있다. 세 출처가 모두 늦을 때만 쓰는 자리로 성격이 바뀌었고 작성법은 `add-curated-override` 6번에 있다
- `traits`는 파생 미러에 없어 백필 인격에서는 비어 있다. 어디서도 읽지 않으므로 영향은 없다
